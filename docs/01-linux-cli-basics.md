# Part 1: Linux CLI Operations, Files/Permissions & Process Management

## 1. System Navigation & Basic CLI Commands
Verifying working directory, current user identity, and kernel version:
```bash
pwd
whoami
uname -a```

Creating directories, manipulating files, and testing text outputs:
```mkdir linux_lab
cd linux_lab
touch test.txt
echo "Linux Server Lab" > test.txt
cat test.txt```
