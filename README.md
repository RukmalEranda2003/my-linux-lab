# My Linux & Cloud Infrastructure Lab 🚀

Welcome to my infrastructure documentation repository! This project documents a multi-part hands-on lab covering Linux command-line operations, cloud security groups, and web server deployment.

---

## 📂 Repository Structure

- `README.md` - Overview of the repository and navigation guide.
- `docs/`
  - [`01-linux-cli-basics.md`](docs/01-linux-cli-basics.md) - Linux CLI operations, file permissions, and process management.
  - [`02-networking-and-security.md`](docs/02-networking-and-security.md) - IP addressing, ports, and AWS Security Group configurations.
  - [`03-server-deployment-nginx.md`](docs/03-server-deployment-nginx.md) - Nginx web server deployment, service management, and custom HTML verification.
- `images/` - Contains all execution screenshots and lab verification images (01 to 10).

---

## 🛠️ Lab Modules Overview

### Part 1: Linux CLI Operations
* System information checking (`pwd`, `whoami`, `uname`)
* Directory and file management (`mkdir`, `touch`, `cat`)
* Permission handling and troubleshooting (`chmod`)

### Part 2: Cloud Networking & Security
* Configuring AWS EC2 Security Groups
* Inbound and outbound traffic rules for SSH (Port 22) and HTTP (Port 80)

### Part 3: Nginx Web Server Deployment
* Installing and enabling Nginx via package manager (`apt`, `systemctl`)
* Testing local connectivity via CLI (`curl`) and web browsers
* Deploying and verifying a custom HTML webpage
